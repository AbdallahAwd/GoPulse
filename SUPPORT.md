# Getting help

- **Reproducible bug:** use the [bug report form](https://github.com/AbdallahAwd/GoPulse/issues/new?template=bug_report.yml).
  Include `gopulse --version` (or the source commit), OS, install method, steps,
  expected behavior and sanitized logs.
- **Setup question:** search existing issues, then open an issue describing the
  command/configuration involved and what you tried. Use example hostnames.
- **Feature idea:** use the [feature request form](https://github.com/AbdallahAwd/GoPulse/issues/new?template=feature_request.yml)
  with the operator workflow, constraints and alternatives.
- **Vulnerability or exposed secret:** follow [SECURITY.md](SECURITY.md). Do not
  report exploit details, credentials or private host information in public issues.

Read the [release guide](docs/releases.md) before installing or upgrading, and
the [contributor guide](CONTRIBUTING.md) before submitting a change. GoPulse is
maintained on a best-effort basis; no response time or commercial support SLA
is promised.
